# Shell, Pipelines, and Job Control

Extended Unix-style shell exercise written in C.

**Concepts:** `fork`, `execvp`, `waitpid`, pipes, `dup`, redirection, process lists, foreground/background execution, signals, and command history.

The original Makefile references course-supplied `LineParser.c/.h` and `looper.c`; those files were not included in the uploaded archive.
